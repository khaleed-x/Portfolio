Imagine building something that would eventually change how the entire world shares information, then having to put a handwritten warning on the computer running it.

That is exactly what happened at CERN.

In 1989, British computer scientist Tim Berners-Lee proposed the World Wide Web while working at CERN, the European Organization for Nuclear Research. His idea was to create a system that would make it easier for researchers to share information across different computers and institutions.

By Christmas 1990, the first website and web server were running on a NeXT computer in his office.

But there was one small operational concern: someone might accidentally switch off the machine.

So a handwritten label was placed on it:

**"This machine is a server. DO NOT POWER IT DOWN!!"**

That computer hosted `info.cern.ch`, the address of the world's first website.

## Why is this interesting?

Today, we deploy applications to cloud platforms, configure managed databases, use containers, and monitor production infrastructure.

Back then, an important part of keeping a web service available was making sure nobody switched off the physical computer hosting it.

The underlying principle, however, remains relevant: software does not operate independently of the systems that run it.

Servers need resources, infrastructure needs attention, and applications need to remain available to the people depending on them.

## One more interesting detail

The World Wide Web was made freely available by CERN on 30 April 1993. That decision helped the technology spread and become the foundation of the web we use today.

A technology that now connects billions of people started with a computer in an office, a simple information-sharing idea, and a very important warning label.

**Sometimes, the history of modern technology is hidden in the smallest details.**
