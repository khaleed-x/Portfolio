We type the names of programming languages every day and almost never ask where they came from. The real stories are stranger, and funnier, than you might expect. Here are the languages I use or keep close, and how they got their names.

## C#: a musical joke

C# was designed at Microsoft by a team led by Anders Hejlsberg, and shipped with the first version of .NET in 2002. The name comes from music. In musical notation, the sharp sign (♯) raises a note by a semitone, so "C sharp" is a playful way of saying "C, but a step higher".

A popular extra explanation is that the ♯ symbol looks like four plus signs stacked together, as if it were "C++" taken one step further. In practice we write it with the `#` on the keyboard, because the real musical sign is not on it.

## Python: named after a comedy show

Guido van Rossum started Python in the late 1980s, and it was first released in 1991. The name has nothing to do with snakes. He was a fan of the British comedy series *Monty Python's Flying Circus* and wanted a short, slightly mysterious name. That is why Python's documentation is full of jokes about spam and eggs.

## PHP: a name that contains itself

PHP began in 1994 as a set of small tools written by Rasmus Lerdorf to track visitors to his online résumé. He called them "Personal Home Page Tools". As it grew into a real language, the name was changed to "PHP: Hypertext Preprocessor". Look closely and you will see that the first letter of the name stands for the name itself. That is called a **recursive acronym**.

## JavaScript: a marketing decision

In 1995, Brendan Eich created the first version of the language at Netscape in about ten days. It was first called Mocha, then LiveScript. It became "JavaScript" because Java was the hottest technology of the moment, and the name was a marketing tie-in.

The two languages are unrelated. They have different designs, different creators and different jobs. The old joke still holds: Java is to JavaScript as car is to carpet.

## TypeScript: JavaScript with a safety net

TypeScript was announced by Microsoft in 2012, and Anders Hejlsberg, the same person behind C#, led its design. The name says exactly what it is: JavaScript with **types**. Valid JavaScript is also valid TypeScript, which is a big reason why adopting it was so easy for teams.

It also means one person had a hand in designing two of the languages I use most. That is a coincidence I enjoy.

## Bonus: Java was almost called Oak

Java was first called Oak, after a tree outside its creator James Gosling's office window. The name was already taken, so the team renamed it. The coffee-themed name stuck, and so did the coffee-cup logo.

## Five quick facts to take with you

1. **The first computer "bug" was real.** In 1947, operators of the Harvard Mark II, working with Grace Hopper's team, found a moth stuck in a relay and taped it into the logbook. The word "bug" was already used by engineers for faults, but this page made it famous.
2. **The first programmer was Ada Lovelace.** In 1843, she published an algorithm for Charles Babbage's Analytical Engine, a machine that was never completed in her lifetime.
3. **"Hello, World!" is older than most developers.** Brian Kernighan used it in a tutorial for the B language in 1972, and it spread widely through the book *The C Programming Language*.
4. **Unix time runs out in 2038.** Many systems store time as a signed 32-bit count of seconds since 1 January 1970. That counter overflows on 19 January 2038, a bug cousin of Y2K that engineers are already fixing.
5. **Git was built in a hurry.** Linus Torvalds started it in 2005 after the Linux kernel lost access to its old version control tool, and it was in use for the kernel's own development within weeks.

## Why this is worth knowing

Names carry history. C# tells you it grew out of the C family, Python tells you its creator wanted fun, and JavaScript tells you the web was once a marketing race. Next time a language name looks silly, remember it probably started as a joke, a hobby, or a sales pitch.
